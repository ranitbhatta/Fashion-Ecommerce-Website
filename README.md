# Bangoprajukti Premium Fashion E-commerce Website

This is a complete rewrite of the supplied fashion landing-page project into a polished, responsive and interactive frontend.

## Files

- `index.html` — premium storefront layout
- `style.css` — complete visual system and responsive styling
- `script.js` — catalog, filters, cart, wishlist, search, quick view, sorting and interactions
- `images/` — place your real product images here

## Expected product image names

```text
images/navy-polo.png
images/black-womenswear.png
images/white-polo.png
images/red-polo.png
images/brown-womenswear.png
```

If an image is missing, the frontend generates a safe SVG placeholder so the interface still works.

## Functional features

- Responsive premium editorial layout
- Sticky glass-style navigation
- Mobile navigation
- Product filtering
- Product sorting
- Color selection
- Quick-view modal
- Product search
- Wishlist
- Shopping cart
- Quantity controls
- Local storage persistence
- Toast notifications
- Newsletter form validation
- Demo checkout flow
- Reduced-motion accessibility support
- No framework dependency

## Live commerce

The checkout action is intentionally a frontend demo. Connect it to your real inventory, order and payment backend before accepting real orders.
